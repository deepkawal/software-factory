# Clinical Workflow Safety Review: AI-Assisted Patient Summary

## Workflow

- Role: clinic staff and clinicians preparing for a visit.
- Output: draft summary displayed before the visit.
- Action influenced: chart review and visit preparation.

## Safety Controls

- [x] Summary labeled "AI-assisted draft".
- [x] Source data links remain visible.
- [x] Clinician review required before content is copied into the record.
- [x] Missing/stale data warning displayed when source fetch is incomplete.
- [x] Failure mode is no summary, not a partial silent summary.

## Decision

- [x] Approved with clinician review and source visibility requirements.
