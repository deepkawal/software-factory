# Example: Clinic Patient Summary AI Assist

Scenario: a clinic wants to add an AI-assisted patient summary for staff before a
visit.

The factory routes the work through:

1. Healthcare change classification.
2. PHI/ePHI data flow mapping.
3. Minimum necessary review.
4. AI data boundary review.
5. Clinical workflow safety review.
6. Release evidence.

The example is intentionally lightweight. It shows the review shape an
engineering team should produce before building and releasing the feature.
