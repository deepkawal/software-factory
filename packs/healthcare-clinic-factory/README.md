# Healthcare Clinic Factory Pack

This pack extends the core factory and regulated-factory overlay for a healthtech
company building software for clinics.

It is written for platform and product engineering teams that need fast delivery
without bypassing PHI/ePHI safeguards, minimum necessary data use, clinical
workflow safety, vendor boundaries, FHIR/interoperability review, and audit-ready
release evidence.

These assets help engineering teams surface healthcare questions earlier in the
SDLC. They do not replace required review by Legal, Compliance, Privacy,
Security, Clinical, Risk, or Regulatory teams.

## Use It For

- PHI/ePHI-aware intake and routing.
- HIPAA-aware engineering review prompts.
- Minimum necessary data review.
- AI clinical-summary boundary review.
- Clinic workflow safety review.
- Vendor/BAA and interoperability prompts.
- Release evidence packages for healthcare changes.

## Example

Start with
`examples/clinic-patient-summary-ai-assist/README.md` for a lightweight scenario:
