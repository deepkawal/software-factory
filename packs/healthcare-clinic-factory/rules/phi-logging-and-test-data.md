# PHI Logging and Test Data Rule

Development, QA, observability, support, and AI workflows use synthetic or
de-identified data by default.

## Never by Default

- PHI/ePHI in logs, traces, analytics, prompts, screenshots, fixtures, issue
  descriptions, generated docs, crash reports, or demo data.
- Raw clinical notes or messages in generic telemetry.
- Patient identifiers in shared support channels.

## Required When Exception Is Approved

- Named owner.
- Explicit purpose.
- Retention and deletion path.
- Access control and audit trail.
- Release evidence link.
