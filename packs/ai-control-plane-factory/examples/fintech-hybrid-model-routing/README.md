# Example: Fintech Hybrid Model Routing

Scenario: a fintech platform adds hybrid routing for AI support workflows.

The factory routes the work through:

1. AI deployment classification.
2. Model routing policy.
3. PII/SSN AI data boundary review.
4. MCP tool access review.
5. Runtime audit-log specification.
6. Release evidence.

The example allows low-risk requests to use approved external APIs while SSN,
customer financial information, KYC, and sanctions contexts stay inside the
trusted boundary.
