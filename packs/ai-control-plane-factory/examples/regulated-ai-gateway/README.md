# Example: Regulated AI Gateway

Scenario: a regulated engineering organization introduces a governed AI endpoint
for general internal AI use.

The factory routes the work through:

1. AI deployment classification.
2. Model routing policy.
3. AI system registry.
4. Prompt and tool policy.
5. Runtime audit-log specification.
6. Release evidence.

The example shows how lower-risk workloads can use approved external APIs while
sensitive workloads require private or self-hosted routes.
